# Real Estate Lead Router

A beginner Python command-line application that simulates a real estate lead routing system.

## Project Overview

This project simulates:

- Incoming client lead generation
- Lead qualification based on budget
- Lead categorization (Hot / Warm / Cold)
- Duplicate lead detection
- Hot lead assignment to available agents

It was built as part of my Python learning journey while practicing program architecture and function design.

---

## Features

### Lead Simulation
Randomly generates:

- Client name
- Budget
- Lead tag

---

### Lead Classification

| Budget Range | Lead Tag |
|-------------|----------|
| 500,000+ | Hot |
| 250,000 - 499,999 | Warm |
| Below 250,000 | Cold |

---

### Duplicate Detection

Prevents duplicate client leads from entering the system.

---

### Hot Lead Dashboard

Displays all hot leads and assigns them to available agents.
